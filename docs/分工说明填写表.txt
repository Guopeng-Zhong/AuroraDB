填写说明
1. 下表是四人小组的拟定模块分工草案；“实际完成内容”必须由对应成员确认后再提交，不能把未参与的工作写成既成事实。
2. 只修改冒号“：”后面的内容，不要删除方括号标题行（如 [成员1]），也不要改动冒号前的字段名。
3. 3 人小组：删除整个 [成员4] 段，并把“验证与文档”的工作并入其他成员。
4. “代表性提交”填写本人在 GitHub 仓库中的提交号（git log --oneline 可查看）或可核对的说明。
5. 各成员“工作量占比”之和应为 100。
6. 本表内容已整理进《AuroraDB_大作业报告.pdf》第 13 节“小组分工与完成情况”；修改本表后需同步更新报告。

四个系统组成部分与对应创新点
1. 数据存储与缓冲子系统：页存储、堆表、B+Tree、WAL、LRU；创新点为扫描感知的预测缓冲策略。
2. SQL 编译与查询执行子系统：词法/语法、绑定、扫描、连接、聚合、事务；创新点为可信查询改写与结果核验。
3. 统计学习与性能优化子系统：统计信息、基数估计、访问成本和实验评估；创新点为域外回退的轻量学习型优化。
4. AI 语义与交互交付子系统：语义算子、AI 接口、Web/CLI、测试、文档和打包；创新点为带批处理、去重、缓存和预算的 AI 语义算子。
