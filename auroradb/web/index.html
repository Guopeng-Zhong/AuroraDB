从第一条 SQL 开始

Ctrl + Enter 执行当前选区，未选中文字时执行整个编辑器。支持多条 SQL；单条写操作自动提交。使用 BEGIN; 与 COMMIT; 或 ROLLBACK; 控制事务。所有浏览器标签页共享同一个事务会话。

点击左侧表名展开字段，点击字段可插入编辑器。右上方选择示例来体验查询、聚合、连接、索引和回滚。执行 EXPLAIN ANALYZE SELECT ...; 可以查看执行计划与实际计数。

示例数据来自启动参数 --demo，仅为空数据库创建，不会覆盖已有表。若数据库为空，请使用 python -m auroradb --demo --web 启动。
